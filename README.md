# Predictive Maintenance & RUL Prediction

Bu proje, motor sensör verilerini kullanarak bir motorun kalan çalışma ömrünü (RUL - Remaining Useful Life) tahmin etmek için hazırlanmıştır.

## Projenin Amacı

Amaç, motorun mevcut durumuna ve sensör verilerine bakarak motorun kaç çalışma döngüsü daha kullanılabileceğini tahmin etmektir.

## Kullanılan Teknolojiler

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Joblib
